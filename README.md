# Haru Shop

> 🇺🇸 Modern desktop application for automating Cookie Run Classic with an interactive documentation website and mock user interface.
>
> 🇹🇭 โปรแกรมเดสก์ท็อปสำหรับช่วยจัดการและทำงานอัตโนมัติในเกม Cookie Run Classic พร้อมคู่มือการใช้งานและหน้าจอจำลอง (Mock UI)

# 📖 Overview | ภาพรวม

Haru Shop is an automation tool designed for **Cookie Run Classic**.

Haru Shop เป็นโปรแกรมช่วยทำงานอัตโนมัติสำหรับ **Cookie Run Classic**

This repository contains:

Repository นี้ประกอบด้วย

- 📚 User Manual — คู่มือการใช้งาน
- 🖥 Interactive Mock UI — หน้าจอจำลองสำหรับทดลองใช้งาน
- 🎨 Frontend Assets — ไฟล์สำหรับแสดงผลหน้าเว็บ
- 📷 Documentation Images — รูปภาพประกอบคู่มือ

The documentation is designed for beginners and provides step-by-step instructions for every feature.

คู่มือถูกออกแบบสำหรับผู้เริ่มต้น โดยอธิบายทุกฟังก์ชันแบบทีละขั้นตอน

---

# ✨ Features | คุณสมบัติ

## 🖥 Device Management | จัดการอุปกรณ์

- Support MuMu Player — รองรับ MuMu Player
- Support LDPlayer — รองรับ LDPlayer
- Multi-device selection — เลือกใช้งานหลาย Emulator พร้อมกัน
- Per-device configuration — ตั้งค่าแยกแต่ละ Emulator ได้

---

## 🤖 Automation | ระบบอัตโนมัติ

- Coin Farming — ฟาร์มเหรียญ
- Party Run
- Box Farming — ฟาร์มกล่อง
- Island Farming — วิ่งเกาะเหรียญ
- Friend Management — จัดการเพื่อน
- Heart Send / Receive — ส่งและรับหัวใจ
- Gift Opening — เปิดของขวัญอัตโนมัติ
- Mission Claim — รับรางวัลภารกิจอัตโนมัติ

---

## 🎮 Gameplay | ระบบการเล่น

- Multi Boost Purchase — ซื้อบูสต์หลายรายการ
- Auto Relic Collection — เก็บ Relic อัตโนมัติ
- Auto Revive — ต่อชีพอัตโนมัติ
- Fast Start — เริ่มวิ่งอย่างรวดเร็ว
- Random Jump Timing — สุ่มจังหวะกระโดดให้เป็นธรรมชาติ

---

## 💎 Treasure System | ระบบสมบัติ

- Auto Treasure Draw — สุ่มสมบัติอัตโนมัติ
- Auto Upgrade — อัปเกรดอัตโนมัติ
- Auto Grind — บดสมบัติอัตโนมัติ
- Favorite Treasure Protection — ป้องกันการบดสมบัติที่ติดดาว

---

## 📊 Monitoring | การติดตามสถานะ

- Live Activity Log — แสดง Log แบบ Real-time
- Statistics Dashboard — แดชบอร์ดสถิติ
- Multi-device Status — แสดงสถานะหลายจอ
- Scheduler — ตั้งเวลาการทำงาน

---

## 🎨 Customization | การปรับแต่ง

- Theme Switching — เปลี่ยนธีม
- Accent Colors — เปลี่ยนสีหลักของโปรแกรม
- Discord Notification — แจ้งเตือนผ่าน Discord
- Language Support — รองรับหลายภาษา
